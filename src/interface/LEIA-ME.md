# `interface/` — tudo que e React

Depende do `nucleo/`. O contrario nunca acontece.

- `design/` — tokens de cor, fonte e espaco. **O unico lugar com valor literal de estilo.**
- `componentes/` — pecas reutilizaveis e burras: recebem props, nao buscam dado.
- `telas/` — as telas do briefing (sincronizacao, busca, detalhe, filtros, paleta).
- `ganchos/` — hooks React compartilhados.
